# 🌿 EcoFome

> Tecnologia contra o desperdício de alimentos.

O **EcoFome** é uma plataforma web que conecta estabelecimentos com sobras de alimentos a pessoas e instituições que necessitam de doações. O objetivo é reduzir o desperdício alimentar e facilitar o acesso a alimentos que ainda estão em boas condições de consumo.

---

## 📖 Sobre o Projeto

Milhares de toneladas de alimentos são desperdiçadas diariamente, enquanto muitas pessoas enfrentam insegurança alimentar.

O EcoFome foi criado para aproximar quem tem alimentos disponíveis para doação de quem precisa deles, utilizando uma interface simples, intuitiva e acessível.

---

## ✨ Funcionalidades

### 📋 Feed de Doações

- Visualização de todas as doações cadastradas.
- Pesquisa por nome ou descrição.
- Filtros por status:
  - Disponível
  - Reservada
  - Todas

### ➕ Cadastro de Doações

- Cadastro de alimentos disponíveis.
- Informações detalhadas sobre a doação.
- Endereço para retirada.
- Categoria dos alimentos.
- Data limite para retirada.
- Contato do estabelecimento.

### 🗺️ Mapa Interativo

- Visualização das doações em mapa utilizando Leaflet.
- Localização dos pontos de retirada.
- Consulta rápida das doações próximas.

### ☁️ Integração com Firebase

- Armazenamento dos dados em nuvem.
- Atualização em tempo real.
- Persistência das doações cadastradas.

### 📱 Responsividade

- Interface adaptada para:
  - Desktop
  - Tablets
  - Smartphones
